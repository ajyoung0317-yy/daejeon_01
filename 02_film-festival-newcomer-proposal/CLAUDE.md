# 영화 기획안 실습

## 주제
국내 영화제 어디에나 적용할 수 있는 **"영화제 입문자 관객 끌어오기 프로그램"** 기획안.
- 문제의식: 영화제 관객은 단골 관객과 첫 입문자로 나뉘며, 입문자는 상영작 선택·예매 방식·분위기가 낯설어 진입하지 못한다.
- 독자: 국내 영화제 프로그래머·홍보 담당자.
- 구조: 공통 기본 틀(입문자 추천 코스, 이용 가이드, 첫 방문 혜택) + 영화제 규모별 추가 항목.

## 작업 흐름 (총괄 = 메인 Claude)
1. **리서치**: 리서처 3명 동시 진행
2. **기획**: planner 구성안 → program-designer → ops-planner → planner 통합
3. **작성**: writer 초안 → fact-checker → writer 수정 → editor
4. **검토**: 검토자 3명 동시 진행 → writer 수정
5. 3~4를 검토자 3명 모두 채택 가능성 "상"이 될 때까지 반복 → `05_최종/`에 최종본

## 작업 원칙
- 사용자는 기획안 작성이 처음이다. 단계마다 결과를 짧게 보고하고 다음 단계를 확인받는다.
- 답변은 필요한 것만 짧게.
