## 구성 (4MAT)
1. **WHY** 왜 무신사에, 왜 지금: 겨울 실내 건조 → 무신사 ‘장벽크림’ 1,301개 중 제로이드 0개 → 같은 축에서 싸우지 않는 시장 포지션
2. **WHAT** 제로이드가 드리는 것: 두 번 검증(병·의원 + 올리브영) → 1차 4종 → 리뷰(아쉬운 점 포함)
3. **HOW** 어떻게 여는가: 가격(단품은 더 비싸지 않게) → 무신사 단독 세트 2종 + 묶음 → 7주 일정
4. **WHAT IF** 무신사에 남는 것: 3개월 목표(주문 1,700건 · 거래액 5.1–8.5천만 원 · 리뷰 300건, 모두 안) → 사계절 확장 → 주고받기 표 → 한 장 요약
