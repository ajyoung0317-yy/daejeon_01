# 온우주 카드뉴스 (초안)

onspace.film_ 인스타그램 게시물을 만든다. 결과물은 `posts/NN_제목/` 폴더 안의 카드 PNG와 `caption.txt`다.
인스타에 올리는 건 사용자가 직접 한다. 스킬은 캡션까지만 쓴다.

## 시리즈와 색

| 종류 | 틀 | 포인트 색 (--point / --hl) | 캡션 첫머리 |
|---|---|---|---|
| 리뷰 | templates/review.html | 노랑 #F2B23A / #FFC861 | #온우주리뷰 N번째 |
| 영화제 리뷰 | templates/festival.html | 핑크 #FF4FA3 / #FF8CC6 | #온우주리뷰 N번째, 영화제 이름 |
| 개봉작 소식 | templates/release.html | 블루 #4FA8FF / #8CC8FF | |
| 계정 소개 | posts/00_계정소개 참고 | 빨강 #E5322D / #FF7A6E | |

- 빨강 #E5322D는 브랜드 색이다. 어떤 시리즈든 로고의 점은 빨강으로 둔다.
- 영화제 리뷰도 리뷰 번호를 이어 간다. N은 `posts/`에 있는 리뷰·영화제 리뷰 폴더 수 + 1이다.
- 영화제마다 색을 바꾸지 않는다. 그 영화제다운 분위기는 이모지, 영화제 이름 라벨 같은 작은 요소로 낸다.

## 작업 순서

한 단계씩 진행하고, 단계가 끝날 때마다 결과를 보여 준 뒤 다음으로 넘어간다.

1. **종류와 번호 정하기**: 어떤 시리즈인지 묻고, `posts/`를 보고 다음 폴더 번호(NN)와 리뷰 번호(N)를 정한다.
2. **폴더와 사진 준비**: `posts/NN_제목_리뷰/`를 만든다. 사용자는 원본 사진을 한글 파일명으로 넣어 준다. `scripts/prep_images.ps1 -Folder <게시물 폴더>`로 `images/`에 영문 이름(r1.jpg, r2.jpg …) 복사본을 만든다. 개봉작은 스틸컷 `-Prefix m`, 포스터 `-Prefix p`. 원본은 건드리지 않는다. 번호는 파일 이름 순서로 붙으니, 스크립트가 보여 주는 "원본 -> 새 이름" 표를 사용자에게 보여 주고 어느 사진을 어느 카드에 쓸지 정한다.
3. **감상 듣기**: 별점, 한 줄 평, 좋았던 점, 보기 전 참고할 점을 사용자에게 듣는다. 사용자가 하지 않은 말이나 별점은 지어내지 않는다.
4. **장 구성 제안**: 들은 내용으로 카드 순서를 표로 보여 주고 확인받는다. 기본 구성은 아래 "카드 구성"을 따른다.
5. **틀 채우기**: 틀을 폴더에 복사하고 내용을 채운다.
6. **사진 중심 맞추기**: 아래 "사진 중심 맞추기"를 따른다.
7. **확인과 수정**: 사용자가 말로 고칠 곳을 알려 주면 반영한다.
8. **PNG 저장**: `scripts/render.ps1 -Html <html 경로>`로 같은 폴더에 `01.png ~ NN.png`를 만든다. 장 수는 카드 개수로 자동 계산된다.
9. **캡션 쓰기**: `references/caption.md`대로 `caption.txt` 초안을 쓰고 함께 다듬는다.
10. **업로드용 정리**: 최종 PNG와 caption.txt를 `업로드용/`에 복사하고, 확인용 `_check/` 폴더는 지운다.

스크립트는 `powershell -ExecutionPolicy Bypass -File <스크립트 경로> ...`로 실행한다. 경로는 이 스킬 폴더(`.claude/skills/card-news/scripts/`) 기준이다.

## 카드 구성

틀의 `[대괄호]` 안을 채운다. 사진이 없는 카드는 검은 배경으로 보인다.

**리뷰 (7장)**: 표지 → 별점과 한 줄 평 → 좋았던 점 1 → 좋았던 점 2 → 좋았던 점 3 → 총평과 추천(보기 전 참고) → 마무리(포스터 + 질문 + @onspace.film_ #온우주리뷰). 06 영화제 리뷰의 에디토리얼 스타일(위쪽 영문 라벨, 얇은 선)을 노랑으로 옮긴 틀이다.

**영화제 리뷰 (영화 수에 따라)**: 표지 → 오늘의 라인업(편명·별점·원픽 태그) → 현장 이야기 → 영화마다 [별점 카드 + 좋았던 점 카드] → 마무리(원픽 포스터 + 질문)

**개봉작 소식**: 표지 → 영화마다 1장(스틸컷 배경 + 제목 왼쪽 작은 포스터 200px + 개봉일·감독 + 오른쪽 아래 배급사 © 크레딧) → 마무리

## 고정 규칙

- 카드는 1080×1350, 글꼴은 Pretendard다.
- 글자 크기와 줄바꿈은 `posts/06_서울국제프라이드영화제_리뷰/review.html`을 기준으로 한다. 사용자가 이 기준에 만족하고 있으니 임의로 바꾸지 않는다.
- 한국어는 `word-break: keep-all`. 끊기면 안 되는 말은 `<span class="nw">`로 묶는다.
- 사진에는 출처를 적는다(오른쪽 아래 `.credit`).
- 말투는 사용자 캡션처럼 "~어요"체.
- HTML은 `파일.html#3`으로 열면 3번 카드만 보인다. 미리보기와 PNG 저장 모두 이 방식을 쓴다.

## 사진 중심 맞추기

사용자가 매번 손으로 맞추던 단계다. 사진이 한쪽으로 치우치면 중심이 안 맞아 보인다고 느낀다.

1. 카드에 쓰는 사진을 하나씩 직접 열어 보고, 중심이 될 대상(인물 얼굴, 주인공, 무대)을 찾는다.
2. 그 대상이 카드 가로 가운데에 오고, 사진 영역(본문 카드는 위쪽 940px)의 위쪽 3분의 1쯤에 오도록 `object-position: X% Y%`를 정한다. 대상이 작으면 `transform: scale()`로 키운다.
3. `scripts/render.ps1 -Html <html 경로> -Check`를 실행한다. 세로 가운데선과 사진 영역 위 3분의 1 가로선을 그린 카드가 `_check/`에 저장되고, 전체를 한 장에 모은 `_check/sheet.png`가 만들어진다. 이 시트를 직접 보고 치우친 카드를 먼저 고친 뒤 사용자에게 보여 준다. 브라우저에서는 `review.html?guide#3`처럼 열면 같은 기준선이 보인다.
4. 사용자가 "3번 조금 왼쪽", "5번 얼굴 더 크게"처럼 말하면 숫자를 고친다.
