# 캡션 쓰는 법 (초안)

posts/00~06의 caption.txt 7개에서 뽑은 공통 구조다. 카드 PNG를 저장한 뒤 바로 초안을 쓰고, 사용자와 함께 다듬는다.

## 말투

- "~어요", "~했어요"체. "~습니다"는 쓰지 않는다.
- 사용자가 직접 보고 느낀 말로 쓴다. 카드에 들어간 사용자 표현을 그대로 가져오고, 하지 않은 감상은 덧붙이지 않는다.
- 한 줄은 짧게(25자 안팎) 끊고, 덩어리 사이에는 빈 줄을 둔다.
- 이모지는 첫 줄 끝에 하나, 별점 줄의 🌌, 덩어리 머리에 몇 개만 쓴다. 영화 분위기에 맞는 것을 고른다(🌕 🐕 🗿 🏳️‍🌈).
- 영화 제목은 <꺾쇠> 안에 쓴다.

## 리뷰 (노랑)

```
[카드 표지와 같은 뜻의 한 줄 훅] [이모지]
#온우주리뷰 [N]번째, [감독/배우] <[영화 제목]>

[상황·인물 소개 1~2줄. 언제 어디서 봤는지가 있으면 함께]

[감상 3~5줄: 좋았던 점을 카드 순서대로 풀어서]

🌌 온우주 별점 [★ 표기] [점수] / 5

[보기 전 참고 한 줄]
[댓글을 부르는 질문] 댓글로 들려주세요.

[해시태그]
```

## 별점 표기

- 지금까지 쓴 표기를 그대로 따른다: 3.5 → ★★★☆, 4.0 → ★★★★☆, 5.0 → ★★★★★.
- 처음 나오는 점수(3.0, 4.5 등)는 표기를 사용자에게 확인한다.
- 카드의 별점과 반드시 같은 숫자를 쓴다.

## 해시태그 순서

15~23개. 아래 순서로 쓴다.

1. 영화 제목, `#제목리뷰` (영화제는 영화제 이름, 약칭·영문)
2. 감독, 주요 배우, 원제
3. 배급사·플랫폼 (#넷플릭스, #찬란, #서치라이트픽처스)
4. 장르·소재 (#우정영화, #퀴어영화, #생존영화)
5. 볼 곳·시기 (#극장개봉, #개봉영화, #주말영화추천, 극장 이름)
6. 일반 (#영화리뷰, #영화추천, #한국영화 또는 #할리우드영화)
7. 항상 마지막: `#온우주리뷰 #onspace_film #영화스타그램` (개봉작은 `#온우주캘린더 #onspace_film`)

## 마무리 확인

- 카드와 캡션의 별점, 날짜, 영화 제목 표기가 같은지
- 사진 출처를 캡션에도 적었는지(영화제 스틸 등 공식 배급사 외 출처일 때)
- 날짜가 들어간 정보에는 "○월 ○일 기준"을 붙였는지
