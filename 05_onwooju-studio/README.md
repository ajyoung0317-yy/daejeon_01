## 일하는 원칙

1. **디렉터가 잇는다** — 에이전트끼리는 서로 부르지 않고, 결과는 파일 경로로 넘깁니다.
2. **감상은 한 곳에서** — 운영자 감상·별점은 작품마다 `감상.md` 한 장에만. 에이전트는 감상을 지어내지 않습니다.
3. **남이 검토한다** — 만든 에이전트가 아닌 정해진 검토자를 새로 불러 검토합니다.
4. **근거로 이어진다** — 자막 한 줄마다 `[S번호]`(조사 출처) · `[운영자]` · `[미확인]` 꼬리표.
5. **배움을 쌓는다** — 작업이 끝날 때마다 `회사/learnings.md`에 한 줄.
6. **토큰을 아낀다** — 검수는 작품당 초안 1번 + 최종 1번으로 묶고, 장면 검토는 디렉터가 직접, 단순 작업(편집·성과 계산)은 가벼운 모델로. 실제 기록(쇼츠 1편 약 60만 토큰)을 보고 정한 규칙입니다.
