# 온우주 브랜드 가이드 (초안 v0.1)

> 작성일: 2026-11-11 · 상위 문서: [운영계획서](운영계획서.md)
> 이미 쓰고 있는 규칙(블로그 문체 가이드, 카드뉴스 스킬, 계정 소개 글)을 모아 **브랜드 기준 하나**로 정리했습니다.
> 채널별 세부 규칙은 각 가이드가 맡고, 이 문서와 다르면 **이 문서를 먼저 고친 뒤** 세부 가이드를 맞춥니다.
> 표시: **[확인]** = 운영자가 정할 것, **[제안]** = 아직 쓰지 않는 새 규칙

## 0. 한눈에 보기 (에이전트용 요약)

- **이름**: 온우주 (영문 onspace). 인스타 `@onspace.film_`
- **슬로건**: 영화 한 편에 담긴 온 우주를 소개합니다 🌌
- **운영자**: 애매필. 그냥 영화와 드라마를 좋아하는 사람, 어린이집 8년 경력
- **약속**: 스포 없이, 확인한 정보로, 누구와 보면 좋을지까지
- **목소리**: 다정하지만 과장하지 않는 친구. 블로그는 "~습니다", 인스타·쇼츠는 "~어요"
- **색**: 브랜드 빨강 `#E5322D` + 시리즈 색 (리뷰 노랑, 영화제 핑크, 개봉작 블루)
- **상징**: 🌌 우주, ★ 온우주별점, 🔒 스포 없어요, 👥 누구와 보면 좋을까?

## 1. 브랜드 핵심

### 1-1. 이름의 뜻
**"영화 한 편에는 한 사람의 우주가 담겨 있다."** 온우주는 그 우주를 하나씩, 천천히 소개하는 채널입니다.
- '온'은 '온전한, 모든'이라는 뜻과 영문 'on'(상영 중, 켜짐)을 함께 담습니다.
- 그래서 작품을 **"우주"**라고 부릅니다. 예: "첫 번째로 소개할 우주는…", "11월, 극장에 걸리는 9개의 우주"

### 1-2. 우리가 누구인가
| 항목 | 내용 |
|---|---|
| 정체성 | 극장 개봉작과 OTT를 가리지 않는 **영화·드라마 추천 채널**. 특정 플랫폼(넷플릭스 등)을 정체성으로 내세우지 않는다 |
| 운영자 | **애매필**. 평론가가 아니라 "그냥 영화를 좋아하는 사람"의 눈높이 |
| 남다른 시선 | 어린이집 8년 경력 → 아이·가족과 볼 때 **주의할 장면을 구체적으로** 알려 줄 수 있다 |
| AI의 역할 | 조사·초안·디자인을 돕는 제작팀. **감상과 별점은 운영자의 것** |

### 1-3. 브랜드 약속 3가지
1. **스포 없이** — 결말과 반전은 말하지 않는다. 🔒 스포 없어요
2. **확인한 정보로** — 개봉일·등급·러닝타임은 공식 자료로 확인한 것만 쓴다
3. **누구와 보면 좋을지까지** — 정보에서 끝내지 않고 "그래서 누구랑, 언제"를 골라 준다 👥

## 3. 목소리와 말투

### 3-1. 공통 성격
| 이런 목소리 | 이런 목소리는 아니다 |
|---|---|
| 다정하다. 친구에게 권하듯 | 가르치려 든다, 평론가처럼 어렵다 |
| 솔직하다. 아쉬운 점도 한 줄 말한다 | 무조건 칭찬한다, 광고처럼 들린다 |
| 차분하다. 여운을 아낀다 | "대박!!", "역대급", "무조건 봐야 할" |
| 구체적이다. 장면·표정·상황으로 말한다 | "재밌어요", "감동적이에요"로 끝낸다 |

### 3-2. 채널별 말투
| 채널 | 말투 | 이모지 | 세부 규칙 |
|---|---|---|---|
| 네이버 블로그 | **"~입니다/~습니다"** 정보형. 문단 끝에 가끔 "~이었죠" | 항목 라벨로만 | `movie-blog-review` 스킬 (`references/style-guide.md`) |
| 온우주별점 한 줄 평 | **구어체** "~더라고요", "~것 같아요" | 🌌 | `movie-blog-review/references/rating-guide.md` |
| 인스타 캡션 | **"~어요/~했어요"** 체. 한 줄 25자 안팎으로 짧게 | 첫 줄 끝 1개 + 덩어리 머리 몇 개 | `card-news/references/caption.md` |
| 쇼츠·릴스 **[제안]** | **"~어요"** 체 말하기. 첫 2초에 질문이나 한 줄 훅 | 자막에 1~2개 | 영상팀 에이전트를 만들 때 정한다 |

### 3-3. 자주 쓰는 브랜드 표현
- 작품을 "우주"로: "다음 우주가 될지도 몰라요", "이번 주의 우주"
- 댓글 부르기: "여러분의 ○○은 무엇이었나요? 댓글로 들려주세요."
- 블로그 도입: "~라면 주목해야 됩니다.", "흔한 ~이 아닙니다."

## 4. 시각 아이덴티티

### 4-1. 색
| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| **브랜드 빨강** | `#E5322D` (밝은 짝 `#FF7A6E`) | 로고의 점, 계정 소개. **어느 시리즈든 로고 점은 빨강** |
| 리뷰 노랑 | `#F2B23A` / `#FFC861` | #온우주리뷰 카드뉴스 |
| 영화제 핑크 | `#FF4FA3` / `#FF8CC6` | 영화제 리뷰 |
| 개봉작 블루 | `#4FA8FF` / `#8CC8FF` | 개봉작 소식 |
| 블로그 초록 | `#0b8a5f` (청록 `#0a7d8c`) | 블로그 본문 글자 강조, 블로그 썸네일 배경. 썸네일엔 빨강 점 로고를 함께 넣는다 |
| 바탕 | 검정 (카드뉴스) / 흰색 (블로그) | |

- 영화제마다 색을 바꾸지 않는다. 분위기는 이모지·라벨 같은 작은 요소로 낸다.
- 새 시리즈를 만들면 이 표에 색을 먼저 추가한다.

### 4-2. 글꼴
- 기본: **Pretendard** (없으면 맑은 고딕)
- 진지한 작품의 '영화 톤' 이미지: 제목만 **Noto Serif KR**(명조)

### 4-3. 사진과 이미지
- **공식 배포 이미지만** 쓴다. 보관함: `영화인스타그램/영화/[작품명]/`
- 출처를 적는다. 예: `📷 스틸 출처: ○○ · 포스터 © 배급사`
- 블로그 본문 사진은 원본 그대로, 썸네일만 직접 만든다 (2026-11-11 운영자 결정).
- 썸네일 글씨는 화면의 25% 이하.

## 5. 브랜드 고정 요소

어느 채널에서나 똑같이 쓰는 장치입니다. 이것이 쌓여야 "온우주다움"이 생깁니다.

| 요소 | 모양 | 규칙 |
|---|---|---|
| 🌌 온우주별점 | `★★★½☆ 3.5` | 5점 만점, 0.5 단위, 3점 = 볼 만함. 공개 전 작품엔 넣지 않는다 |
| 🔒 스포 없어요 | 도입 바로 뒤 | 모든 리뷰의 기본값 |
| 👥 누구와 보면 좋을까? | 대상 + 상황 + 이유 | 혼자·연인·친구·가족·아이와·부모님과 중 1~2개 |
| #온우주리뷰 N번째 | 인스타 캡션 둘째 줄 | 번호는 블로그·인스타 공통으로 이어 가기 **[확인]** |

### 기본 해시태그
- 인스타: `#온우주리뷰 #onspace_film` + 작품·장르 태그
- 블로그: 작품명 + 플랫폼 + 장르 + 배우 + 상황 태그, 5~10개

## 6. 하지 말 것

- 결말·반전 말하기, 반전이 있다고 암시하기
- 운영자가 하지 않은 감상이나 별점을 지어내기
- 근거 없는 최상급 ("역대 최고", "무조건 봐야 할")
- 확인하지 않은 날짜·수치
- 공식 배포가 아닌 이미지, 다른 글의 문장 복사
- 협찬 사실을 숨기기 (협찬·초대 콘텐츠는 반드시 표기)
