# 성과 기록

운영자가 숫자를 알려 주면 디렉터(메인 대화)가 아래 CSV에 한 줄씩 넣는다. 성과팀(`performance-analyst`)은 읽기만 한다.
엑셀로 열어도 한글이 깨지지 않게 UTF-8(BOM)으로 저장되어 있다.

## 채널-월별.csv — 채널 전체 숫자 (매달 말일 기준)
- 월: `2026-11` · 채널: `블로그` / `인스타` / `유튜브`
- 지표 예: `일평균방문자`, `월방문자`, `이웃수`, `팔로워`, `월도달`, `구독자`, `월조회수`
- 값: 숫자만 · 기준일: `2026-11-30` · 메모: 특이사항

## 콘텐츠별.csv — 글·카드·영상 하나씩
- 발행일 `2026-12-07` · 채널 · 작품 · 형식(`리뷰`, `개봉작정리`, `테마추천`, `결산`, `쇼츠`) · 조회수 · 좋아요 · 댓글 · 저장 · 공유 · 기준일 · 메모
- 모르는 칸은 비워 둔다. 0과 빈칸은 다르다.

## 숫자 찾는 곳 (운영자)
- 네이버 블로그: 내 블로그 → 통계 (방문자 수, 조회수 순위)
- 인스타그램: 프로페셔널 대시보드 → 인사이트 (팔로워, 도달, 게시물별 저장·공유)
- 유튜브: YouTube 스튜디오 → 분석 (구독자, 조회수, 쇼츠별 조회수)
