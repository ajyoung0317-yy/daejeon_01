# 온우주별점 가이드

> 리뷰 글의 별점 블록 규칙입니다. 이름은 항상 **온우주별점**입니다. ("온우주 평점", "별점" 단독 표기 금지)
> 점수와 한 줄 평은 **초안**입니다. 운영자가 직접 보고 고칩니다. 그래서 블록 바로 아래에 반드시 ✍️ 수정 안내를 둡니다.
> 공개 전 프리뷰·공개 예정 글에는 별점을 넣지 않습니다.

---

## 1. 블록 형식 (후기 섹션 안, 그대로 쓰기)

```markdown
⭐ ***온우주별점*** (5점 만점)

🌌 총점 : ★★★★☆ 4.0

💭 한 줄 평 : (구어체 2~3문장)

✍️ [직접 작성: 좋았던 점과 아쉬웠던 점 각 1가지 (노스포) / 별점·한 줄 평은 초안이니 직접 본 감상으로 수정]
```

- 위치: **후기 섹션**, 소제목 아래 공식 스틸 자리 다음. 별도 소제목을 만들지 않는다.
- 세부 항목(이야기·연기·연출·몰입감) 점수는 넣지 않는다. 총점 하나만.
- 각 줄 사이에 빈 줄 1개.

## 2. 총점

- 5점 만점, 0.5점 단위. 별은 항상 5칸(빈 별 ☆ 포함), 반 개는 `½`. 예: `★★★½☆ 3.5`
- 기준점 3점 = 볼 만함. 3점에서 더하고 빼는 방식.

| 점수 | 의미 |
|---|---|
| 5.0 ★★★★★ | 인생작 |
| 4.5 ★★★★½ | 올해의 작품 후보 |
| 4.0 ★★★★☆ | 강력 추천 |
| 3.5 ★★★½☆ | 추천, 취향에 맞으면 충분히 즐김 |
| 3.0 ★★★☆☆ | 볼 만함 |
| 2.5 ★★½☆☆ | 호불호 |
| 2.0 이하 | 아쉬움 ~ 비추천 |

- 초안 점수는 research의 평단·관객 반응(로튼 토마토, 국내 관객 평점, 씨네21 등)을 참고해 정하되, 외부 평점을 그대로 환산하지 않는다.

## 3. 한 줄 평

- **구어체 2~3문장.** 본문 합쇼체와 달리 친구에게 말하듯 부드럽게: `~더라고요`, `~것 같아요`, `~제맛인 영화입니다`.
- 극장 개봉작이면 **왜 큰 화면에서 봐야 하는지**를 강조한다. OTT 작품(넷플릭스·티빙 등)이면 **어떤 날·누구와 보면 좋은지**로 마무리한다.
- 아쉬운 점(호불호 포인트)을 한 문장 섞어 균형을 맞춘다.
- 결말·반전 암시 금지.

### 예시 (실제 사용한 글)

> 💭 한 줄 평 : 존 말코비치의 연기와 진짜 이스터섬에 와 있는 것 같은 풍경까지, 큰 스크린으로 봐야 제맛인 영화입니다. 대사가 많아 호불호는 갈릴 수 있지만 맥도나 감독 특유의 블랙 유머는 여전하더라고요. 야생마가 달리는 섬 풍경은 극장에서 못 보면 정말 아쉬울 것 같아요.
