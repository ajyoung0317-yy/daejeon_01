# 원 소스 멀티 유즈 설계 (v0.2)

> 작성일: 2026-11-11 · 상위 문서: [운영계획서](운영계획서.md) 4장 "한 작품을 조사하면 블로그 → 카드뉴스 → 쇼츠로 세 번 쓴다"
> 표시: **[확인]** = 운영자가 정할 것

---

## 0. 한눈에 보기

- **목표**: 작품 이름 하나만 말하면 조사 → 감상 받기 → 블로그 → 카드뉴스 → 쇼츠가 **같은 재료로** 이어진다.
- **지금 문제**: 재료가 폴더 3곳에 흩어져 있고, 운영자 감상은 매번 다른 곳(인스타 캡션, 블로그 ✍️)에서 찾아야 한다. 하트 오브 비스트 쇼츠 때도 캡션을 뒤져서 감상을 찾았다.
- **핵심 제안 2가지**
  1. **작품 폴더 = 스틸 보관함** (`영화인스타그램/영화/[작품]/`). 여기에 **`감상.md`** 한 장을 두고, 세 채널이 모두 이 파일에서만 감상·별점을 가져온다.
  2. **작품 장부** (`회사/작품장부.md`) 한 장으로 작품마다 어느 채널까지 끝났는지 본다.
- **먼저 풀어야 할 것**: 이 폴더(`영화`)와 블로그 폴더(`netflix-blog/netflix-blog-automation`)가 **같은 GitHub 저장소를 따로 받아 둔 두 복사본**이고, 서로 다른 커밋이 쌓여 갈라져 있다 (3장).

## 1. 지금 재료가 있는 곳

| 재료 | 위치 | 만드는 것 |
|---|---|---|
| 조사 자료 `research.md` | `netflix-blog/netflix-blog-automation/output/[주제]/` | `movie-blog-review` 스킬 |
| 블로그 원고 `final.md` | 같은 곳 | 같음 |
| 공식 스틸·포스터 | `영화인스타그램/영화/[작품]/` | 운영자 |
| 카드뉴스·캡션 | `영화인스타그램/posts/NN_[작품]_리뷰/` | `card-news` 스킬 |
| 쇼츠 | `영화/output/[주제]/shorts/` (블로그와 같은 작품 폴더) | 영상팀 에이전트 |
| 회사 문서·에이전트 | `영화/회사/`, `영화/.claude/agents/` | — |

**이름도 제각각이다**: `하트오브비스트`(블로그·스틸) / `03_하트오브비스트_리뷰`(인스타) / `하트-오브-비스트`(쇼츠, 합치면서 `하트오브비스트`로 옮김). `card-news` 스킬은 띄어쓰기·`-`·`_`·번호를 빼고 비교하는 규칙으로 이미 맞추고 있다.

## 2. 통합 흐름

```
작품 이름
  │
  ├─ ① 조사      research.md 없으면 만든다 (있으면 재사용)
  ├─ ② 감상 받기  감상.md 없으면 운영자에게 한 번만 묻는다
  │
  ├─ ③ 블로그     research + 감상.md → ✍️ 자리를 감상.md 문장으로 미리 채움
  ├─ ④ 카드뉴스   research + 감상.md + 스틸
  └─ ⑤ 쇼츠      research + 감상.md + 스틸 (+ 카드뉴스 캡션 말투)
        │
        └─ 작품장부.md 갱신, learnings.md 한 줄
```

- ③④⑤는 서로 기다리지 않는다. 운영자가 원하는 채널만 골라서 돌린다.
- **감상은 한 번만 받는다.** 지금은 블로그 ✍️, 카드뉴스 "감상 듣기", 쇼츠 brief에서 세 번 묻는다.

### `감상.md` 형식 (작품 폴더에 하나)
```
# [작품] 감상 — 운영자 원문
본 날짜·장소: 2026-10-30, ○○극장 (협찬 아님)
온우주별점: 4.0
한 줄 평:
좋았던 점: 1. … 2. … 3. …
아쉬운 점 / 보기 전 참고:
누구와 보면 좋을까:
기억에 남는 장면 (노스포):
```
- **운영자만 쓰거나, 운영자가 말한 것을 그대로 옮긴다.** 에이전트는 이 파일의 뜻을 바꾸지 않는다.
- 이미 올린 카드뉴스 캡션이 있는 작품은 캡션에서 옮겨 첫 판을 만들고 운영자가 확인한다.
- 협찬·시사회 여부도 여기에 적는다 → 모든 채널이 같은 표기를 쓴다.

## 3. 먼저 풀어야 할 것: 갈라진 두 복사본

| 폴더 | 들어 있는 것 | 이 폴더에만 있는 커밋 |
|---|---|---|
| `클로드/영화` (지금 폴더) | 회사 문서, 영상팀, 브랜드 통일 | 회사 문서·가이드 통일, 영상팀 구성 (2개) |
| `클로드/netflix-blog/netflix-blog-automation` | 블로그 결과물 8편 (스킬이 여기에 씀) | 로또 1등도 출근합니다 리뷰 (1개) |

둘 다 GitHub `netflix-blog-automation` 저장소를 가리킨다. 어느 쪽이든 올리면(push) 다른 쪽과 부딪친다.

**결정 (2026-11-11)**: **A안 — `영화` 폴더를 본사로** 합쳤다. 로또 커밋을 병합하고, 블로그 폴더의 결과물 8편(작업 중이던 수정 포함)을 `영화/output/`으로 복사했다. 쇼츠는 `output/하트오브비스트/shorts/`로 옮겼다. 블로그 폴더의 가이드·에이전트 미커밋 수정은 옮기지 않았다(보관 폴더에 남음).

(검토했던 안)
- **A안 (추천)**: `영화` 폴더를 본사로. 블로그 폴더의 로또 커밋과 결과물을 가져오고, `movie-blog-review`·`card-news` 스킬의 블로그 경로를 `영화/output/`으로 바꾼다. 회사 문서·영상팀·쇼츠가 이미 여기 있다.
- B안: 블로그 폴더를 본사로. `영화` 폴더의 커밋 2개를 그쪽으로 가져온다. 스킬 경로는 그대로.
- 어느 쪽이든 합친 뒤 남은 폴더는 지우지 않고 이름만 바꿔 보관한다.
