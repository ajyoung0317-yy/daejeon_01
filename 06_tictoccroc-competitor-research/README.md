# 06. 째깍원정대: 돌봄 서비스 경쟁사 상세페이지 조사 MVP

> 콘텐츠마케터 실습 · 2026-11-16 · Claude Code
> 학습용 MVP(Minimum Viable Product)이며, 조사한 회사들과 관계없습니다.

**경쟁 돌봄 서비스 5곳과 우리 회사(째깍악어)의 상세페이지를 매일 손으로 비교하던 조사를 줄여 줍니다.** 대표 문구, 광고, 요금, 별점을 다시 조사하고, 앞 조사와 비교해 바뀐 곳을 찾아 한 화면에 보여 줍니다.

- 고객: 아이 하원 시간은 됐는데 돌봄이 필요한 여성 직장인
- 경쟁사: 맘시터, 자란다, 아워스팟, 단디헬퍼, 시터넷 + 째깍악어(우리)
- 칸 7개: 대표 문구, 광고 문구(메타), 광고 시작일, 요금 방식, 공개된 최저 가격, 서비스 종류, 앱스토어 별점
- 규칙: 조사일과 출처 링크를 붙이고, 못 찾은 값은 "못 찾음"으로 둡니다. 값은 지어내지 않습니다.
