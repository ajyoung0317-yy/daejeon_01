# 06. 째깍원정대: 돌봄 서비스 경쟁사 상세페이지 조사 MVP

> 콘텐츠마케터 실습 · 2026-11-16 · Claude Code
> 학습용 MVP(Minimum Viable Product)이며, 조사한 회사들과 관계없습니다.

**경쟁 돌봄 서비스 5곳과 우리 회사(째깍악어)의 상세페이지를 매일 손으로 비교하던 조사를 줄여 줍니다.** 엄마가 고르는 기준으로 다시 조사하고, 앞 조사와 비교해 바뀐 곳을 찾아 한 화면에 보여 줍니다.

- 고객: 어린이집·유치원 하원 시간은 됐는데 돌봄이 필요한 여성 직장인
- 경쟁사: 맘시터, 자란다, 아워스팟, 단디헬퍼, 시터넷 + 째깍악어(우리)
- 칸 16개
  - 엄마 기준 11개: 서비스 지역, 이용 가능 나이, 공개된 최저 가격, 아이 추가 요금, 당일 신청, 시간 연장, 취소·환불, 선생님 검증, 보험·사고 대응, 돌봄 소식, 앱스토어 별점
  - 마케터 기준 5개: 대표 문구, 광고 문구(메타), 광고 시작일, 요금 방식, 서비스 종류
- 규칙
  - 조사일과 출처 링크를 붙이고, 값은 지어내지 않습니다.
  - 빈칸은 "공개 안 함 / 회원에게만 공개(가정) / 확인 못 함 / 해당 없음"으로 나눠 적습니다.

## 화면에서 보는 것 (mvp.html)
- **오늘 할 일:** 바뀐 곳과 확인할 칸 수
- **부모 눈으로 본 비교**
  - 세 줄 결론: 앞서요 / 우리만 공개 / 보강할 것
  - 회사별 "공개·가능 N/11" 합계
  - 기본 조건·비용·안심 묶음 점수판: 묶음은 접었다 폈다 할 수 있어요.
- **바뀐 곳**, 그리고 "더 보기" 안에 우리만 공개한 것·빠진 것과 가격 비교
- **네이버 광고 탭:** research2.csv
