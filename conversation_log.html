2026.10.28–10.29 · 실습생과 Claude의 대화를 단계별로 정리 · 요청은 원문, 결과는 요약

01

무신사에 낼 제로이드 브랜드 입점 제안서를 만들 거야. 홈페이지의 브랜드 스토리(연혁), 피부과학(피부장벽·MLE·디펜사마이드), 제품 라인, 제품 리뷰를 취합해줘. 난 담당자가 아니고 회사 소개서를 만드는 실습생이야.

RESULT
  • 연혁(2002 런칭 ~ 2020 12개국 수출), 피부장벽·MLE®·디펜사마이드™, 6개 라인 31종 + 의료기기, 리뷰를 한 문서로 정리
  • 2020년 이후 연혁은 홈페이지에 없어 담당자 확인 필요로 표시
02

제안서 초안 만들기

RESULT16장 슬라이드 초안(브랜드 → 피부과학 → 제품 → 리뷰 → 입점 제안). 가격·담당자 등은 대괄호로 비워 둠.
03

리뷰를 요약 말고 세세하게. 무신사 MD에게 입점을 제안하는 제안서로, 어떤 퍼소나가 어떤 라이프스타일 여정에서 만족하는지 어필하고 싶어. 문답하면서 점진적으로 개선하자. html 웹페이지로.

RESULT
  • 홈페이지 리뷰 429건 전수 수집 · 평균 4.90, 5점 92%, 민감성 69%
  • 퍼소나 5명과 하루 여정, 리뷰 10건을 사용 전·사용법·사용 후로 재구성한 웹페이지 첫 버전
04

무신사 고객층은 2030 직장인. 겨울 히터로 건조해지는 피부, 수분 관련 퍼소나로. 성수 팝업은 빼고 무신사 뷰티 입점으로. 제로이드 상품 전반에 사진도 같이.

RESULT겨울 사무실 퍼소나 4명(건성·수부지·지성 남성·야근)으로 재설계, 제품 사진 30종과 현미경 사진 추가, 처음 구성(브랜드 → 제품 → 리뷰 → 제안)으로 복귀.
05

제품 사진이 너무 많아. 대표 8개 정도로만.

RESULT대표 8종 카드로 축소, 나머지 23종은 라인별 이름 목록으로.
06–08

틀이 너무 딱딱해, 핀터레스트 레퍼런스 느낌으로. 타이틀 글씨체도 눈에 띄게. → 제품 누끼 따줘, 제목은 직장인과 제로이드로. → 표지 구려, 제품 3개만, 깨끗한 제품 소개 느낌으로.

RESULT파란 그라디언트·둥근 카드 디자인 시도 → 제품 배경 제거(누끼) → 제목 “출근부터 퇴근까지, 직장인 피부엔 제로이드” → 흰 배경 제품 3종 표지.
09

다시 시작해보자. 색감이 내 미감과 안 맞아. 무신사 × 제로이드 느낌의 감각으로 표현해줘.

RESULT무신사식 흑백 에디토리얼로 전면 재디자인. 굵은 영문 ZEROID 워드마크, 상품 목록형 카드, 올리브 그린은 포인트로만.
10–12

지금 나온 거 저장하고 더 수정하자. → 내용이 너무 많아, 줄여. → 너무 많이 줄였어. 그리고 직장인의 겨울 건조한 피부를 더 강조했으면.

RESULT버전 저장 후 바탕화면 폴더로 이동 → 축약본 → 중간 분량으로 복원하고 ‘01 WINTER OFFICE’(히터 아래 하루 5개 시간대) 섹션과 겨울 색 추가.
13

무신사 MD 입장에서 괜찮은지 말해봐. 아니면 수정하고, 겨울로만 가도 괜찮은지도.

RESULT
  • 판단: 브랜드 소개서로는 좋지만 입점 제안서로는 매출·가격·조건이 부족
  • 한 장 요약, 사계절 로드맵, 입점 조건표 추가
  • 겨울은 런칭 테마로 쓰고 브랜드는 사계절로 보여주는 것이 효과적
14

홈페이지 리뷰가 오래된 느낌이야. 네이버 스토어 수딩크림 리뷰와 올리브영 제로이드 베스트 제품 리뷰도 가져와줘.

RESULT
  • 올리브영: 37개 제품 판매 중, 인텐시브 크림 4.8 (14,336건), 수딩 크림 4.8 (10,456건), 2026년 9–10월 최신 리뷰 반영
  • 이미 올리브영에서 팔고 있어 ‘살 곳이 없다’ 논리를 ‘올리브영에서 검증, 무신사에서 확장’으로 수정
  • 네이버 스마트스토어는 접속이 차단돼 가져오지 못함
15

네가 무신사 MD야. 입점시켜줄 것 같아? 뭐가 부족한지 다시 검토해봐.

RESULT“미팅은 잡지만 바로 확정은 어렵다.” 부족한 점: 가격 정책, 무신사만의 차별점, 매출 데이터, 경쟁 분석, 마케팅 투자, 일정·운영, 보고용 형식.
16

그럼 1–5 순위로 정리해서 제안서에 넣어보자.

RESULT

  • 추가 섹션: 가격 정책(올리브영 동일가), 무신사 단독 기획, 경쟁 비교표, 주 단위 일정(12월 첫 주 오픈)
