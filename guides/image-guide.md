# 본문 이미지 가이드

> 블로그 본문에 넣는 **설명용 이미지**(표, 다이어그램, 카드, 인용)와 **대표 이미지(썸네일)**를 HTML+CSS로 만들고 PNG로 캡처하는 규칙입니다.
> 작품 스틸컷은 여기서 만들지 않습니다. 스틸컷은 넷플릭스 공식 배포본을 사람이 직접 넣습니다(`seo-guide.md` 4장).

---

## 0. 두 종류의 이미지 마커

| 마커 | 뜻 | 누가 채우나 |
|---|---|---|
| `[IMAGE: 유형 / 내용]` | 이 가이드로 **만들어서** 넣는 설명용 이미지 | image-maker 에이전트 |
| `[이미지: 창 프레임 / 장면 설명]` | 넷플릭스 **공식 스틸컷** 자리 | 사람(직접 업로드) |

- `[IMAGE: …]`의 `유형`은 `비교 표`, `단계`, `카드`, `인용` 중 하나다. 유형이 없거나 맞지 않으면 내용을 보고 고른다.
- 두 마커를 합쳐 본문 이미지 수(단일 리뷰 6~10장)를 맞춘다.

---

## 1. 이미지 종류 4가지 (글 내용에 맞게 선택)

| 번호 | 종류 | 언제 쓰나 | 템플릿 |
|---|---|---|---|
| 1 | **비교 표** | 둘 이상을 같은 기준으로 비교할 때 (두 부부, 시즌1 vs 시즌2, 비슷한 작품 비교) | `guides/image-templates/1-compare-table.html` |
| 2 | **단계별 다이어그램** | 순서·절차·일정을 보여줄 때 (영화제 → 개봉 → 공개, 시청 순서) | `guides/image-templates/2-steps.html` |
| 3 | **핵심 포인트 카드** | 요점 3~5개를 정리할 때 (관람 포인트, 볼 이유) | `guides/image-templates/3-cards.html` |
| 4 | **인용/강조 박스** | 중요한 한마디를 강조할 때 (감독·배우 발언, 한 줄 총평) | `guides/image-templates/4-quote.html` |
| – | **대표 이미지** | 글마다 1장 | `guides/image-templates/0-thumbnail.html` |

### 고르는 기준
- 표에 넣을 기준이 2개 이상이고 비교 대상이 2~3개면 **비교 표**.
- 순서가 의미 있으면(날짜, 단계) **단계**. 3~5단계.
- 순서 없이 나란한 요점이면 **카드**. 3~5개.
- 문장 하나가 주인공이면 **인용**. 출처(누가, 어디서)를 반드시 적는다.

## 2. 공통 규칙

- **제작:** 모두 HTML + CSS로 만들고, Python + Playwright로 PNG 캡처한다.
- **배경 톤:** 본문(흰 바탕, 초록 `#0b8a5f` 강조)과 어울리게. 템플릿의 `:root` 색 토큰을 바꾸지 않는다.
- **텍스트는 최대한 짧게:** 이미지는 보조 수단이다. 자세한 설명은 본문에 쓴다.
  - 제목(`h1`) 15자 이내, 라벨(`// …`) 12자 이내
  - 카드·단계 한 칸: 굵은 글씨 10자 이내 + 보조 문장 15자 이내
  - 표 한 칸 12자 이내, 인용문 2줄 이내(줄당 18자 안팎)
- **코드 블록 스타일:** 디자인 요소로 쓴다. 맥 창 프레임(빨강·노랑·초록 점), 상단 파일명(`compare.md` 등), `// 라벨`, 번호 `01 02 03`.
- **사실 정보:** 이미지에 들어가는 날짜·이름·수치는 **draft.md 본문에 이미 있는 것만** 쓴다. 새 정보를 이미지에 추가하지 않는다.
- **글꼴:** Pretendard(웹폰트), 없으면 맑은 고딕. 이모지는 대표 이미지에만 1개까지.
- **저작권:** 작품 스틸·포스터를 HTML에 직접 넣지 않는다. 예외는 대표 이미지(5장 참고).

## 3. 크기와 캡처

| 종류 | 크기 | 비고 |
|---|---|---|
| 본문 이미지 | 폭 860px 고정, 높이는 내용에 맞게 | 2배 해상도로 저장 → 1720px 폭 PNG |
| 대표 이미지 | 1080 × 1080px 고정 | 2배 해상도 → 2160px PNG |

- 캡처는 `.canvas` 요소만 잘라 찍는다. 그래서 페이지 아래 빈 여백이 생기지 않는다.
- 캡처 명령 (영화 폴더에서 실행):
  ```bash
  py tools/capture.py 입력.html 출력.png [입력2.html 출력2.png ...]
  ```
- 필요: `pip install playwright`, Microsoft Edge (별도 브라우저 다운로드 불필요).

---

## 4. 템플릿 쓰는 법

1. 맞는 템플릿 HTML을 복사해 `output/[주제]/images/html/body-N.html`로 저장한다.
2. **`<body>` 안의 내용만 바꾼다.** `<style>`의 공통 토큰과 프레임 부분은 그대로 둔다.
   - 파일명(`compare.md` 등)은 내용에 맞게 바꿔도 된다. 영문 소문자 + `.md`.
3. 항목 수에 맞게 조정한다.
   - 비교 표: 열 2~3개, 행 3~5개. 열이 3개면 세 번째 열에 `class="col"`만 붙인다.
   - 단계: `.step`과 `.arrow`를 짝으로 늘리거나 줄인다. 마지막(현재·핵심) 단계에 `now`.
   - 카드: 3개(기본 3열), 4개면 `<div class="cards n4">`(2×2), 5개면 기본 3열(3+2).
   - 인용: 강조할 단어 1~2개만 `<em>`.
4. 캡처 후 6장의 검수를 한다.

## 5. 대표 이미지 (썸네일)

`seo-guide.md` 4-3과 `style-guide.md` 3장을 따른다.
- 1080 × 1080, 라벨 1개 + 문구 2줄, **글씨 영역은 화면의 25% 이하**, 분할(콜라주) 금지.
- 문구는 draft.md 맨 위 작성 메모의 `[썸네일]` 항목을 그대로 쓴다. 없으면 제목과 도입에서 2줄을 만든다(줄당 14자 이내).
- 라벨: `공개 예정` / `영화 리뷰` / `드라마 리뷰` / `영화 큐레이션` 중 글 종류에 맞게.
- 배경:
  - 기본은 템플릿의 어두운 초록 그라데이션 + 코드 장식 2줄(`> netflix.play("작품명")`, `> release: 날짜`).
  - `output/[주제]/images/source/`에 사람이 넣어 둔 **공식 배포 이미지**가 있으면 `.canvas`의 `background-image`로 쓰고 코드 장식은 뺀다. 인터넷에서 이미지를 직접 받아 쓰지 않는다.

## 6. 캡처 후 검수 (최대 3회 반복)

PNG를 직접 열어 눈으로 확인한다.

| 확인할 것 | 고치는 법 |
|---|---|
| 아래쪽에 과도한 빈 여백 | `.canvas`/`.body` padding 확인, 고정 height 제거 |
| 글자가 잘리거나 박스 밖으로 넘침 | 문구 줄이기 → 그래도 넘치면 글자 크기 2px씩 낮추기 |
| 한 단어가 두 줄로 쪼개짐 | `word-break: keep-all` 확인, 문구 줄이기 |
| 요소가 비뚤어지거나 높이가 들쭉날쭉 | flex/grid 구조를 템플릿 그대로 되돌리기 |
| 글꼴이 깨지거나 □로 보임 | 해당 문자(특수문자·이모지) 빼기 |
| 썸네일 글씨가 25%를 넘음 | 문구 줄이기 또는 글자 크기 낮추기 |

3회 안에 해결되지 않으면 그 이미지는 그대로 두고 문제를 보고한다.

## 7. draft.md에 넣는 형식

마커 한 줄을 아래처럼 바꾼다(경로는 draft.md 기준 상대 경로).

```markdown
![두 부부 비교 표](images/body-1.png)
<sub>두 부부 한눈에 보기</sub>
```

- 대체 텍스트(`![ ]` 안)는 이미지 내용을 한 문장으로. `seo-guide.md` 4-2의 alt 규칙을 따른다.
- 캡션(`<sub>`)은 이미지 제목. 직접 만든 이미지라 `ⓒ Netflix`는 붙이지 않는다.
- 대표 이미지는 본문에 넣지 않는다. 작성 메모의 `[썸네일]` 항목에 경로(`images/thumbnail.png`)만 적는다.
